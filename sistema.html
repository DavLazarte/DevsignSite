Notas de uso

  • Un solo h1 por página. Las secciones usan h2.
  • Todo control interactivo tiene foco visible y área de 44 px como mínimo.
  • Las imágenes llevan width, height y alt descriptivo. Las decorativas, alt="".
  • El cian y el verde no se usan como texto sobre blanco.
  • Los placeholders no se publican: se reemplazan por los archivos de assets/img/PENDIENTES.md.
